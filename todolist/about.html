About Todo List

Welcome to our ToDo List Application

This application helps you manage your daily tasks easily. You can add tasks, mark them as completed, edit them, and delete tasks when they are no longer needed.

Features

  • Add new tasks
  • Mark tasks as completed
  • Undo completed tasks
  • Edit existing tasks
  • Delete tasks
  • Filter tasks by All, Pending, and Completed
  • Dark Mode
  • Customize button colors
  • Save tasks using Local Storage

Technology Used

This project was created using:

  • HTML
  • CSS
  • JavaScript
  • Local Storage
