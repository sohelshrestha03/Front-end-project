Help Center

Need help using our ToDo List application? Find answers to common questions below.

1. How to Add a Task?

Enter your task in the input box and click the Add button. Your task will appear in the task list.

2. How to Complete a Task?

Click the green tick button (✓) beside a task to mark it as completed. Click the undo button (↩) to make it pending again.

3. How to Edit a Task?

Click the yellow edit button (✎), enter the updated task, and confirm your changes.

4. How to Delete a Task?

Click the red delete button (🗑) beside the task and confirm that you want to delete it.

5. How to Filter Tasks?

All: Displays every task.

Pending: Displays unfinished tasks.

Completed: Displays finished tasks.

6. How to Change Dark Mode?

Open the Settings page and click the Dark Mode button to switch between light and dark themes.

7. How to Change Button Colors?

Open Settings and use the color selectors to change the colors of the complete, undo, edit, and delete buttons.

8. How to Clear All Tasks?

Go to Settings, click Clear All, and confirm the action. This removes all saved tasks.

9. Are My Tasks Saved?

Yes. The application uses browser Local Storage to save tasks. Tasks are stored in the current browser on your device.

Still Need Help?

If you experience a problem, check that JavaScript is enabled and that your browser allows Local Storage.
